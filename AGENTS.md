# Инструкции для AI-агентов (AGENTS.md)

## Порядок работы с задачами

1. **Источник задач:** Все задачи на разработку находятся в папке `tasks/`. Берите задачи в работу последовательно (по номеру файла) из папки `tasks/`.
2. **Структура задачи:** Каждая задача в `tasks/` содержит:
   - **Статус** (`TODO` / `IN_PROGRESS` / `DONE`)
   - **Цель**
   - **Критерии приёмки**
   - **Ограничения**
   - **Результаты проверок**
3. **Выполнение и отчётность:**
   - Перед началом работы над задачей изучите её цель, критерии приёмки и ограничения.
   - После выполнения задачи обновите файл самой задачи в `tasks/`: установите статус `DONE`, отметьте выполненные критерии приёмки и заполните раздел «Результаты проверок» (команды запуска и фактический вывод).
   - **Обязательно записывайте выполненные задачи в этот файл (`AGENTS.md`)** в раздел «Журнал выполненных задач» ниже.
